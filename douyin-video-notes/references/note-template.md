# md 笔记模板与标签规则

每篇笔记是一个独立的 Markdown 文件，命名 `NNNN_标题前20字.md`（NNNN 为序号，与索引表对应）。

## 模板

```markdown
# {发布内容标题}

> **博主**：{up 主名称}｜**平台**：抖音{（共创标注）}
> **标签**：{知识领域标签，多标签用 / 分隔}｜**关键词**：{转写产物 keywords，可选}
> **发布时间**：{YYYY-MM-DD HH:MM}｜**时长**：{约 X 分 Y 秒}
> **视频链接**：{https://www.douyin.com/video/{video_id}}
> **所属合集**：{合集名称（第 N 集）或"主页作品"}

---

## 一句话结论

{用 1~2 句话概括视频核心结论}

## 章节要点

{来自妙记 chapters 章节摘要；无则省略}

## 核心要点

{按内容整理的分点要点，可含数据表格}

## 金句

{视频中的原话引用，可选}

## 行动建议

{可执行的建议；纯知识/训练类无建议则省略}

## 完整逐字稿

{妙记 transcript 原文，保留时间戳；无口播视频标注"本视频无系统口播"，附真实转录内容}

---

*生成方式：douyin-video-notes skill*
```

## 标签规则（up 主名称 / 标题 / 知识领域）

### up 主名称（必填）
- 取自视频页作者名。
- 批量场景必须与目标账号一致；共创/他号发布标注如"陈石（与@粗人共创）"或"超鹿学院（发布）；出镜：陈石"。

### 发布内容标题（必填）
- 视频标题原文，保留原标点；文件名中截取前 20 字并去除非法字符。

### 知识领域标签（必填，本 Skill 新增要求）
- 按**内容主题**判定，可多标签，用 `/` 分隔；置于笔记头部"标签"行。
- 参考领域词表（可扩展）：营养 / 健身 / 减脂 / 增肌 / 拳击训练 / 睡眠 / 补剂 / 肠道健康 / 断食 / 饮食误区 / 运动表现 / 健康科普。
- 判定依据：标题 + 逐字稿核心内容，而非标题表面词。例："睡前吃碳水有助于睡眠" → `睡眠/营养`；"B-丙氨酸全解析" → `补剂/运动表现`；"最后一回合体能告警" → `拳击训练`。
- 视频无实质知识内容（纯训练集锦、宣传短片）→ 领域标 `无口播训练集锦` 或按实际标注，不硬凑标签。

## 其他约定

- 核心要点中的数据、数字必须来自逐字稿，不得编造；拿不准的标注"原文未明确"。
- 完整逐字稿是硬要求：必须原文粘贴（含时间戳），"一个字不要少"，禁止摘要化改写。
- 每篇笔记底部保留生成方式注记，便于追溯。

## SRT 字幕文件（可选但推荐）

每篇笔记交付时，同步生成同名 SRT 字幕文件（`NNNN_标题.srt`，与笔记同目录）：

```bash
python3 "<douyin-video-notes skill 根目录>/scripts/transcript_to_srt.py" "<笔记md路径>" [--total <视频总秒数>]
```

- 输入即笔记 md（自动提取"完整逐字稿"章节），无需额外素材。
- SRT 供剪辑软件（剪映/PR）生成字幕、双语字幕、二次剪辑时间定位使用。
- 无口播视频（训练集锦/图文）不生成 SRT。
- SRT 文本与逐字稿同源，个别 ASR 同音字错误如需精确可人工校对。
