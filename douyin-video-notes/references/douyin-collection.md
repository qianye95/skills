# 抖音账号作品采集（列表与合集）

目标：给定账号主页，拿到该账号全部视频清单（video_id + 标题 + 链接），并确保清单纯净（只含目标作者）。

## 1. 主页 URL 与身份锁定

- 主页格式：`https://www.douyin.com/user/{sec_user_id}`，sec_user_id 形如 `MS4wLjABAAAA...`。
- 账号名 → sec_user_id：浏览器搜索该账号名，进入其主页，从地址栏取 sec_user_id；或从任意视频页作者链接 `a[href*='/user/']` 提取。
- **批量采集前必须锁定目标 sec_user_id 前缀**，后续所有作者归属验证都与之比对。

## 2. 作品列表采集（主页"作品"tab）

- 页面滚动加载列表，用 `bu.read_all` 读视频条目（字段建议：`["text","href"]`），limit 上限 200。
- **已踩死的坑（不要重试）**：
  - read_all 单轮上限 200 条；列表 DOM 超过 200 时最老视频在尾部被截断，无法一次读全。
  - `bu.js` / `bu.cdp` / `bu.http_get` 在该场景不可靠（空返回或 CDP session 错误）。
  - `bu.find(中文关键词)` 在长列表中返回 None。
  - snapshot(full=True) 大 DOM 输出被截断（约 10k 字符）。
  - 未登录访客仅能加载约 200 条作品（主页计数可能 300+）；登录态加载上限仍存在。
- 可行做法：滚动 + 分批 read_all 取可见区条目，合并去重；超 200 条的部分改走合集通道。

## 3. 合集通道（早期内容）

合集 URL：`https://www.douyin.com/collection/{collection_id}/1`（页码后缀）。

- 在主页找到"合集"tab，可列出该账号所有合集（名称 + 链接 + 集数）。
- 逐个合集进入，逐集 read_all 采集，跨合集按 video_id 去重。
- **注意**：合集页只渲染部分集数（实例：标注 59 集的合集页面仅可获取前 6 集），且滚动到底可能截断——无法穷尽时如实报告缺口。

## 4. 作者归属验证（必须步骤，防杂质）

合集页和列表会混入**其他作者的推荐位视频**（实测：154 条合集候选中有 116 条是杂质）。

验证方法（逐条）：
1. 打开候选视频页 `https://www.douyin.com/video/{video_id}`。
2. `bu.read_all("a[href*='/user/']", fields=["href","text"])` 取作者主页链接。
3. 提取 href 中的 sec_user_id，与目标账号前缀比对。
4. 判定：
   - 前缀匹配 → 目标账号作品，保留。
   - 不匹配 → 杂质，剔除（移入"杂质剔除"目录 + 记录清单：视频ID/页面作者名/原笔记名/来源）。
   - 页面含共创标识但作者非目标账号 → 共创/他号发布，单列清单交用户裁决。

实测样例：陈石 sec_user_id 前缀 `MS4wLjABAAAAoAQuW`；杂质作者"老雷瘦"前缀 `MS4wLjABAAAAtd7xX9jpm13...`，可一眼区分。

## 5. 输出清单

生成 CSV：序号 / video_id / title / url / 播放量 / 时长 / 发布时间 / 来源合集（或"主页作品"）。编号建议与最终笔记文件名对应（如 `0001_标题前20字.md`）。

## 6. 互动指标采集（账号对标 / 选题研究，可选但推荐）

批量流程在**作者验证那一步**（本来就要打开每个视频页）顺便采集公开互动数据：**播放量 / 点赞 / 评论 / 收藏 / 转发**，用于账号对标和选题研究。

方法（浏览器，作者验证同一轮完成）：
1. 打开视频页后，等页面加载完（4-5 秒），用 `bu.get_page_text()` 或 `bu.read_all("span, div", fields=["text"], limit=...)` 提取互动栏文本。
2. 页面互动栏文本形如 `播放 1.2万 · 点赞 856 · 评论 23 · 收藏 412 · 转发 15`（具体布局随版本变化，以实测为准）。
3. 正则提取数字 + 单位（万/亿），换算为整数：
   - `1.2万` → 12000；`3.5亿` → 350000000；`856` → 856。
   - 拿不到某项时写"未获取"，**不填 0**（0 与未获取分开，避免误导）。
4. 记入分片结果 CSV 的指标列（播放量/点赞/评论/收藏/转发），合并时写入索引总表；也可单独生成 `指标表.csv`（含发布时间、标题、四项互动、按点赞降序排列，供对标分析）。

注意：
- 指标是采集时刻的页面快照，会随时间变化；记录采集时间。
- 视频删除/不可见时对应指标记"未获取"。
- 互动数据用于客观统计，不用于平台外的传播分析推断。
